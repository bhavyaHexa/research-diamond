# Temporal AA files
- shaders/037: frame blend (progressive accumulation); 064/065 + velocity.*: motion vectors; 069: TAA resolve; ao-temporal: temporal AO (optional)
- engine-snippets/: minified extracts from src/engine (Na, Ga, za jitter table, Jp TAA, Bp/Dp velocity). Names are minified; depend on engine base classes (Bt, Aa, Mt).
- docs/: reverse-engineering notes (see sections on Progressive/TAA)
